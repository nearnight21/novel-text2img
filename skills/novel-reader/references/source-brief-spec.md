# 角色视觉材料包规范

材料包的目标是让视觉 Agent 理解“这个人为什么不是通用题材角色”，而不是保存角色的全部资料。

使用 `${HERMES_SKILL_DIR}/templates/source-brief.md` 作为结构，并遵守以下要求。

## 1. 当前目标

写清角色 ID、姓名、时期或场景。时期不确定时必须明确说明，不能混用多个阶段。

## 2. 角色一句话核心

用一句话概括最不可替代的特点。它是视觉设计中心，不是生图提示词。

## 3. 原文硬特征

只保留会直接影响外貌、体型、年龄感、伤势、服装、装备或非人特征的明确事实。

每项重要事实包含：

- 简洁结论；
- 一小段关键原文；
- 章节、文件或可回看的位置；
- 若适用，注明只属于哪个时期。

不要把体温数值、完整时间线、章节清单、声音信息或与首图无关的剧情塞进主体。

## 4. 人物感与反差

提取三到五条真正决定“像不像”的气质、行为模式和内外反差。用关键行为或场景作为依据，不写空泛形容词。

## 5. 明确避免

只写会把角色误导成另一种题材模板的禁止项，通常不超过八条。禁止项必须来自原作人物定位或已经出现过的明显误读。

## 6. 需要设计的问题

列出原文没有解决、可由视觉 Agent 补完的内容。未知项不阻塞材料包交付。

## 7. 冲突与不确定

只记录会改变画面的真实冲突。若只是原文没写，放入“需要设计的问题”，不要升级成证据审查。

## 长度原则

材料包应足够支撑视觉判断，但不追求固定字数。关键摘录通常三到八段；若角色跨时期复杂，可适当增加，但不要复制整章或建立完整证据库。
